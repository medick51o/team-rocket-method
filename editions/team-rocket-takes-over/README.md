# TRM: TEAM ROCKET TAKES OVER! 😼🚀
### a Team Rocket Method series · the agentic AI playground
### a multi-agent dress-up tool & talking cat simulator

**The honest pitch:** the original Team Rocket Method (this repo's foundation) set out to be
the real deal — a rigorous multi-vendor development methodology. This series branched so
far it became its own show — an official BRANCH of TRM: same universe, same law, new season, and it owns what it is: a **dress-up tool for AI models and a
talking cat simulator** whose actual product is *engagement* — it keeps a human genuinely
having fun while doing (and learning) real multi-agent orchestration. The discipline
underneath is real; the costume department is the point. If the method is the gym, this is
the game that makes you show up.

## Install
Copy this folder to `~/.claude/skills/team-rocket-takes-over/`, then `/team-rocket-takes-over` in any
Claude Code session. Requires this repo's TRM law docs (the tool runs ON the method).
Supersedes the earlier seasons (`the-new-edition`, `cat-in-charge`) when installed.

## Why it exists
Because engagement is the rarest resource in learning agentic AI — and a talking cat that
runs your dev shop like a Saturday-morning villain org turns out to be a renewable source
of it. Genuinely fun. That's the whole pitch.
